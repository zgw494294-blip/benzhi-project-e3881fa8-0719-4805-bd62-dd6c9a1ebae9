# caption-release-gate

`caption-release-gate` 是面向字幕编辑员、无障碍质量复核员和内容发布负责人的字幕交付准入工作台。它围绕单个字幕包完成建档、不可变修订导入、确定性时轴质检、问题整改或例外申请、独立复核、内容冻结、发布清单签发和清单验证。

服务同时提供响应式浏览器页面和同源 JSON API，不需要 Node 构建链。业务数据保存在本地 SQLite 中；包版本、幂等结果和带前序摘要的审计事件在短事务内共同提交。

## 构建

```text
go build ./cmd/server
```

## 运行

默认只监听高位回环地址 `127.0.0.1:19081`：

```text
go run ./cmd/server
```

启动后访问 `http://127.0.0.1:19081/workbench`。可以通过参数选择其他高位回环端口和数据库文件：

```text
go run ./cmd/server -addr=127.0.0.1:19120 -db=caption-release-gate.db
```

也可以设置纯端口号 `PORT`，服务会固定绑定到 `127.0.0.1:<PORT>`。`PORT` 和 `-addr` 都拒绝低于 `1024` 的端口，`-addr` 还会拒绝 `0.0.0.0`、主机名和非回环 IP。

## 测试

运行全部单元测试和持久化集成测试：

```text
go test ./...
```

运行有界端到端自检：

```text
go run ./cmd/server -addr=127.0.0.1:19081 -selfcheck -selfcheck-timeout=20s
```

自检会启动真实 HTTP 监听，通过与浏览器相同的 JSON API 依次完成建档、修订导入、质量检查、例外申请、独立复核、冻结、签发、清单验证和审计链验证，随后在时限内关闭服务并自行退出。自检使用内存 SQLite，不会改动默认数据库文件。

## 业务约束

- 每个写命令都携带 `expectedVersion` 与不少于 8 个字符的 `idempotencyKey`；过期版本会返回冲突，相同幂等键会复用首次结果。
- cue 导入会规范化时码、说话人和文本，并拒绝非法时码、重复 `cueId`、重复序号以及与帧率或时码制式不一致的数据。
- 固定规则集 `caption-qc/1.0.0` 检查时间重叠、最短间隔、显示时长、每秒字符数、单行长度、空文本和阅读顺序。
- 独立复核员不能是当前修订提交者。尚有未处置问题或未解决阻断问题时不能通过。
- 冻结摘要覆盖排序后的 cue、质量问题、规则摘要、复核决定和审计链尾；签发后的清单可区分有效、内容不匹配、篡改和未知签发者。
- 冻结或签发后只能通过导入新修订显式重开流程，已有修订、决定、清单和审计事件保持不可变。

## 主要 API

页面入口为 `GET /workbench`。同源 API 位于 `/api/v1`，包括交付包、修订、检查、例外、替代修订、复核、冻结、签发、历史和清单验证路由。健康检查入口为 `GET /healthz`。
